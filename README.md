# GTA VI Timer

تطبيق iPhone شخصي بـ SwiftUI وWidgetKit، لنظام iOS 17 فأحدث. تاريخ البداية الافتراضي **19 نوفمبر 2026 الساعة 00:00 محليًا** ثابت ولا يتصل بأي مصدر لتغييره. الاسم والتاريخ والخلفية قابلة للتعديل. صورة `Artwork.jpg` هي الصورة الأولى المرفقة نفسها، مضمّنة في التطبيق والامتداد؛ لا يوجد تنزيل عند التشغيل. التطبيق بلا حسابات أو خادم أو إعلانات أو تحليلات.

## البناء على macOS

```sh
brew install xcodegen
xcodegen generate
open GTAVITimer.xcodeproj
```

المصدر الموثوق لإعدادات المشروع `project.yml`. المشروع المولّد مرفق أيضًا بعد نجاح البناء. اختر scheme `GTAVITimer` ثم iPhone Simulator، وشغّل Product > Test. للبناء غير الموقّع للأجهزة:

```sh
bash Scripts/build-unsigned.sh
```

ينتج `build/GTA-VI-Timer-unsigned.ipa` بعد التأكد من وجود `PlugIns/TimerWidget.appex` والملف التنفيذي. **IPA غير الموقّعة لا تُثبّت مباشرة**. مسار GitHub Actions يدوي من Actions > iOS manual build > Run workflow؛ ينفذ اختبارات المحاكي، بناء الجهاز، ويحفظ الأدلة والمشروع وIPA لمدة 14 يومًا. لا يحتاج شهادات ولا يضعها في السجلات. حالة التنفيذ الفعلية موثقة في `VERIFICATION.md`.

## التوقيع والتثبيت

1. على Mac مع Xcode وحساب Apple Developer يدعم App Groups، اختر Team نفسه للتطبيق `GTAVITimer` والامتداد `TimerWidget`.
2. سجّل معرفين فريدين للتطبيق والامتداد (الافتراضيان `com.kaido1070.gtavitimer` و`com.kaido1070.gtavitimer.widget`). حدّثهما في إعدادات المشروع إذا لزم.
3. أنشئ `group.com.kaido1070.gtavitimer` وفعّل المجموعة نفسها لكلا App IDs وكلا provisioning profiles. عند تغييرها حدّث `APP_GROUP_IDENTIFIER` لكلا الهدفين. يظهر خطأ صريح في التطبيق إذا لم تتوفر الحاوية أو فشلت الكتابة؛ لا يدّعي الحفظ أو المشاركة عند الفشل.
4. وصّل iPhone، فعّل Developer Mode، اختر الجهاز، وشغّل Run. أو Archive ثم Export باستخدام Development/Ad Hoc وملفات توقيع تشمل الجهاز. وقّع الامتداد المضمّن والتطبيق مع صلاحيات المجموعة؛ إعادة توقيع التطبيق وحده غير كافية. ملفات المصدر وIPA غير الموقعة ليست تطبيقًا جاهزًا للتثبيت.
5. افتح التطبيق مرة. لإضافة ودجت الرئيسية: اضغط مطولًا على الشاشة > تحرير > إضافة أداة > GTA VI Timer واختر الصغير أو المتوسط أو الكبير.
6. لشاشة القفل: اضغط مطولًا على شاشة القفل > تخصيص > شاشة القفل > منطقة الأدوات تحت الساعة > GTA VI Timer واختر الودجت المستطيل.

## سلوك العد والصور

- الأيام = الجزء الصحيح من الثواني الفعلية المتبقية ÷ 86400، سواء في التطبيق أو الودجت، وليست عدد تبدلات التاريخ. عند الموعد وبعده تظهر «وصل الموعد». تغيّر المنطقة الزمنية يعيد تفسير تاريخ الموعد كبداية يوم محلي؛ أيام التوقيت الصيفي قد تكون 23 أو 25 ساعة.
- التطبيق يحدّث العرض كل ثانية أثناء ظهوره فقط. الودجت يطلب جدولًا لثلاثة أيام، عند حدود تغيّر الأيام وعند الموعد، مع فرص تحديث كل ساعة وسياسة تجديد بعد ست ساعات. النظام يقرر وقت التحديث الفعلي ولا يضمن اللحظة المحددة. الحفظ والعودة إلى التطبيق وتغيّر المنطقة الزمنية تطلب إعادة تحميل الجدول.
- الصورة الأصلية كاملة مع خلفية تمويه عند اختلاف النسبة، للمحافظة على الشخصيتين والشعار؛ الرقم فوق الصورة بتظليل موضعي. منتقي صور النظام يستورد نسخة JPEG مصغرة إلى 1600 بكسل، دون صلاحية وصول شامل للألبوم. تحفظ الصورة قبل ملف الإعدادات الذري في App Group؛ تبقى النسخ السابقة لدعم القراء المتزامنين ولقطات الودجت.
- الشاشة الرئيسية تدعم الألوان في الوضع الكامل؛ إعدادات صبغة iOS قد تغيّرها. **شاشة القفل تستخدم accessoryRectangular: صورة مربعة صغيرة داخل المستطيل وعدد فوقها. وضع vibrant يحوّل الصور إلى لون موحّد.** التباين النهائي يتبع خلفية القفل وإعدادات الجهاز. صورة SwiftUI الملوّنة أو اختبار بطاقة منفردة ليست دليلًا على مظهر شاشة القفل الحقيقي.
- مرجع Apple: [Widget rendering modes](https://developer.apple.com/documentation/widgetkit/preparing-widgets-for-additional-contexts-and-appearances)، [Accessory rectangular](https://developer.apple.com/documentation/widgetkit/widgetfamily/accessoryrectangular).

الصورة المرفقة وشعارات اللعبة ملك لأصحابها؛ المشروع للاستخدام الشخصي المطلوب.
